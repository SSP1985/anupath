Lesson 1: The SELECT Statement

The `SELECT` statement is used to fetch data from a database. To select all columns from a table, you use the `*` wildcard. Try typing the following query in the editor and clicking "Run Query":

SELECT * FROM employees;

This will return all data from the `employees` table. Go ahead and give it a try!

5 Essential SQL Commands for Beginners

  1. SELECT — fetch columns/rows
    SELECT name, salary FROM employees;
  2. WHERE — filter rows
    SELECT * FROM employees WHERE department = 'Engineering';
  3. ORDER BY — sort results
    SELECT name, salary FROM employees ORDER BY salary DESC;
  4. GROUP BY — aggregate
    SELECT department, COUNT(*) AS headcount FROM employees GROUP BY department;
  5. JOIN — combine tables
    SELECT e.name, d.name AS dept FROM employees e JOIN departments d ON e.department = d.name;

Tip: Press Shift + Enter to run the query from the editor.
